## Machine-checking rules

1. Parse the four-column table above and require exactly the 15 `SL221-...` IDs shown.

Require every row's `Candidate evidence owner` to be `core`, `committee`, or `core+committee`; do not infer ownership from prose. `core` resolves to this bundle's `sol-terra-parallel-orchestration/SKILL.md`; `committee` resolves specifically to `agent-committee-orchestration/SKILL.md`, a different file in the same bundle — a checker must scan the file the row's owner names, never default every row to the core skill.

4. Treat the source version and source SHA-256 above as immutable baseline metadata. Do not replace them with a local checkout path, a current candidate hash, or a generated digest.
5. A green candidate test does not waive an absent external conformance check; installation-specific Hermes/WebUI capabilities remain conditional.
